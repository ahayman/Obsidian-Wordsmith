## Initial Release

Wordsmith is an Obsidian plugin for synonym, antonym, and definition lookup directly within your editor.

### Features

**Multi-Source Lookup**
- Query multiple thesaurus sources simultaneously
- Built-in support for Datamuse API (no API key required)
- Local offline databases: WordNet and Moby thesaurus
- Optional premium API integrations: Merriam-Webster, Big Huge Thesaurus, WordsAPI, API Ninjas, Altervista, and Free Dictionary

**Word Relationships**
- Synonyms
- Antonyms
- Related words
- Hypernyms (more general terms)
- Hyponyms (more specific terms)

**Two Lookup Modes**
- Full modal with tabbed sources, search filtering, and results grouped by definition
- Quick replace popover for fast word substitution near your cursor

**Spelling Suggestions**
- Automatic spelling correction suggestions for misspelled words
- Offline Hunspell dictionary support
- Online spelling suggestions via Datamuse

**Performance**
- Result caching with configurable cache size
- Streaming results that load progressively
- Lazy loading of additional relationship types

**Mobile Support**
- Touch-friendly interface
- Swipe gestures for tab and definition navigation
